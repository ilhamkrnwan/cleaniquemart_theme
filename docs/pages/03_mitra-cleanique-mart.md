## 4. Implementasi Tema WordPress (`cleaniquemart-theme`)

- **File Template**: `page-mitra.php`
- **Template Parts**:
  ```php
  get_template_part('template-parts/hero-mitra');
  get_template_part('template-parts/outlet-filter');
  get_template_part('template-parts/outlet-directory');
  get_template_part('template-parts/cta-open-new-city');
  ```
- **JavaScript UI**: Real-time filtering berdasarkan atribut `data-city` atau `data-region` tanpa reload halaman.

## 5. Integrasi Plugin (`cleaniquemart-core`)

- **Query Loop CPT**: Halaman ini mengulang data dari CPT `cleanique_outlet`:
  ```php
  $args = array(
      'post_type'      => 'cleanique_outlet',
      'posts_per_page' => -1,
      'orderby'        => 'title',
      'order'          => 'ASC',
  );
  $query = new WP_Query($args);
  ```
- **Shortcode Alternatif**: `[cleanique_outlet_locator show_map="yes"]`.
